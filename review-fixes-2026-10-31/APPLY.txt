PATCH TARGETS

01-snapshot-fixes.patch
  Target: the root of inkling-contrib-review-2026-10-29.

  Applying this patch changes original files, so the historical MANIFEST.sha256

03-mlx-vlm-cache-fixes.patch
  Target: mlx-vlm after inkling-fast-path ee1be2540c.
  Fixes disk restoration of temporal window caches and batched cache state
  restoration, including pending right padding. Includes regression tests.

04-mlx-vlm-quantization-fix.patch
  Target: the same mlx-vlm tree, after patch 03.
  Lets uniform KV quantization reach eligible nested caches after memory/disk
  prompt-cache restoration or batch-row extraction. Honors explicit conversion
  hooks and delayed thresholds; nested sliding and auxiliary caches are retained.
  Includes regression tests covering those actual reuse paths.

APPLICATION

to the relevant patch in this folder:

  git apply /absolute/path/to/patch

mlx-lm, and 03 followed by 04 is for mlx-vlm. These source patches
have been tested on the
